# FoFPZ.github.io

Личный сайт **FoFPZ** — одностраничная визитка на чистом HTML, CSS и JavaScript (без сборки и зависимостей). Размещается на GitHub Pages.

## Структура

```
├── index.html          # вся разметка страницы
├── assets/
│   ├── css/style.css   # стили (тёмная и светлая темы)
│   └── js/main.js      # анимации, меню, печатающийся текст
└── CNAME               # домен для GitHub Pages
```

## Как редактировать

Во всех файлах места для замены помечены комментарием **`ЗАМЕНИТЕ`**:

- `index.html` — текст «Обо мне», факты, теги интересов, карточки проектов, ссылки на соцсети и почту;
- `assets/js/main.js` — фразы печатающегося текста в шапке.

Просто откройте нужный файл, найдите комментарий и поменяйте содержимое.

## Локальный просмотр

Откройте `index.html` в браузере, либо запустите локальный сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация

Сайт публикуется автоматически через GitHub Pages при пуше в ветку, из которой настроен деплой (обычно `main`).
